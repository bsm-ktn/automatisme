L'idée en 30 secondes

Le piège du nom

Dans EtherNet/IP, IP veut dire Industrial Protocol, pas « Internet Protocol ».

EtherNet/IP, c'est le réseau Ethernet de tous les jours — câble, prise RJ45, switch, adresse IP — qui transporte CIP (Common Industrial Protocol), la langue des automates Rockwell. Il est apparu en 2001 ; c'est un standard ouvert, géré par l'ODVA : d'autres marques l'utilisent aussi.

DeviceNet et ControlNet parlent la même langue CIP. C'est pour ça que, dans Studio 5000, on configure tous ces réseaux de la même façon.

Fiche d'identitéEtherNet/IP
Câble et priseEthernet standard : catégorie 5e ou 6, prise RJ45 (ou M12 dans les endroits durs)
Vitesse de nos appareils10 ou 100 Mbit/s, réglée automatiquement
Adresseune adresse IP unique par appareil, ex. 10.20.49.80, masque 255.255.255.0
PortsTCP 44818 messages explicites · UDP 2222 E/S implicites
Deux rôlesScanner : ouvre les connexions et commande (l'automate L30ER). Adaptateur : répond et obéit (1734-AENT, PowerFlex 525). Un automate peut être les deux.
EtherNet/IP = Ethernet + TCP/IP + CIP. Le scanner (l'automate) ouvre les connexions ; les adaptateurs répondent.

Deux façons de parler : implicite et explicite

C'est LA notion à retenir. Sur EtherNet/IP, un appareil échange de deux façons, qui n'ont rien à voir.

Implicite · les E/S

Comme un abonnement : le journal arrive chaque matin, même sans nouvelles.

  • La connexion s'ouvre une fois, au démarrage.
  • Ensuite, les données partent toutes seules à chaque RPI, même si rien n'a changé.
  • Transport UDP, port 2222 : rapide, sans accusé de réception — le paquet suivant arrive de toute façon.
  • Exemples : entrées et sorties du 1734-AENT, commande et état du PowerFlex 525, tags produits / consommés entre deux automates.
  • À programmer : rien. On ajoute l'appareil dans I/O Configuration.
Explicite · les messages

Comme un appel téléphonique : une question, une réponse, seulement quand on en a besoin.

  • Un appareil pose une question (« donne-moi le tag Compteur »), l'autre répond.
  • Transport TCP, port 44818 : la livraison est vérifiée, mais pas à heure fixe.
  • Exemples : l'instruction MSG, le PanelView (FactoryTalk View), Studio 5000 en ligne, RSWho.
  • À programmer : une MSG dans une ligne. Rien pour l'écran ni pour le PC : ils demandent eux-mêmes.

Unicast ou multicast ? Un producteur peut envoyer ses données à un seul consommateur (unicast, le choix habituel aujourd'hui) ou à plusieurs à la fois (multicast). En multicast, il faut un switch géré avec IGMP snooping, sinon les paquets inondent tous les ports.
Implicite = cyclique, au RPI : pour piloter la machine. Explicite = à la demande : pour afficher, régler, programmer.
4

Le RPI : à quel rythme ?

RPI (Requested Packet Interval) : l'intervalle demandé entre deux paquets.

RPI = 20 ms → les données sont mises à jour toutes les 20 ms. On le règle dans Studio 5000, onglet Connection de l'appareil (ou dans la connexion d'un tag consommé). Seuls les échanges implicites ont un RPI.

1 · Il ne suit pas le programme

Les E/S réseau arrivent à leur rythme, pas au début du scan. Une entrée peut donc changer au milieu du programme (regardez la première rangée de la chronologie ci-dessus).

Une valeur doit rester la même du début à la fin du scan ? Copiez-la au début avec l'instruction CPS, puis travaillez sur la copie.

2 · Aussi lent que possible

Chaque connexion envoie 1000 ÷ RPI paquets par seconde, dans chaque sens. Diviser le RPI par deux double le travail de l'automate, du switch et de l'appareil.

Règle Rockwell : réglez le RPI à la vitesse dont l'application a besoin, pas plus vite.

3 · Quand les paquets cessent

Après quelques RPI sans paquet, la connexion tombe : triangle jaune dans I/O Configuration (code 16#0203).

Côté appareil : les sorties de l'AENT prennent leur état de défaut (en général coupées), et le variateur réagit selon son réglage de perte de communication.

Ajouter un appareil : 6 gestes

  1. Hors ligne, clic droit sur Ethernet → New Module.
  2. Choisissez le modèle (1734-AENT, PowerFlex 525, 1769-L30ER…).
  3. Donnez un nom (il devient le début des tags) et l'adresse IP — la même que sur l'appareil !
  4. Révision et Electronic Keying : Compatible Module. (Exact Match exige la même révision ; Disable Keying ne vérifie rien : à éviter.)
  5. Onglet Connection : le RPI.
  6. Téléchargez, passez en ligne : aucun triangle jaune.
L'appareil n'est pas dans la liste ? Installez son fichier EDS (menu Tools → EDS Hardware Installation Tool) : il décrit l'appareil pour Studio 5000. Sinon, un Generic Ethernet Module avec les numéros d'assemblages donnés dans la documentation de l'appareil.

Les appareils, un par un

Pour chacun : son rôle, comment régler son adresse, ce qu'il devient dans Studio 5000 et le piège classique.

CompactLogix 1769-L30ER

scanner
Son rôle
Le chef : il exécute le programme et ouvre les connexions d'E/S vers l'AENT, le variateur et l'autre automate.
À savoir
Deux ports EtherNet/IP (avant et arrière) : on peut chaîner les appareils ou faire un anneau (DLR). Jusqu'à 16 nœuds EtherNet/IP dans I/O Configuration, 1 Mo de mémoire, jusqu'à 8 modules 1769 à côté de lui.
Son adresse
La première fois, par le câble USB : FactoryTalk Linx (ou RSLinx) le trouve, puis Controller Properties → Internet Protocol. Ou avec BOOTP-DHCP Server, grâce à l'adresse MAC de l'étiquette.
Voyants réseau
LINK 1 / LINK 2 : le câble est branché. NS : l'état des connexions (voir le chapitre 7).
Le piège
Le PanelView et le PC ne comptent pas dans les 16 nœuds ; l'AENT, le variateur et PLC2, oui.

PanelView Plus 600

client · messages explicites
Son rôle
L'écran de l'opérateur. Il fait tourner une application FactoryTalk View ME (fichier .mer) et lit ou écrit les tags de l'automate par leur nom, en messages explicites.
Son adresse
Dans le terminal lui-même : Terminal Settings → Networks and Communications. Même sous-réseau que l'automate.
Le lien avec l'automate
Dans FactoryTalk View Studio : un raccourci (shortcut) FactoryTalk Linx qui pointe vers PLC1, pour l'ordinateur ET pour l'écran (Runtime).
Le piège
On ne l'ajoute pas dans I/O Configuration. L'écran n'affiche pas les valeurs ? Vérifiez le raccourci (bon automate, bonne adresse) et le nom exact des tags.

Variateur PowerFlex 525

adaptateur
Son rôle
Il obéit : l'automate lui envoie Start, Stop et la consigne ; il renvoie son état et sa fréquence réelle — en implicite, au RPI. Le port EtherNet/IP est intégré.
Son adresse
Paramètre C128 = 1 (adresse par paramètres ; 2 = BOOTP, le réglage d'usine), puis C129 à C132 = 10.20.49.90 et C133 à C136 = 255.255.255.0. Coupez et remettez l'alimentation.
Pour qu'il obéisse au réseau
P046 [Start Source 1] = 5 « EtherNet/IP » et P047 [Speed Reference1] = 15 « EtherNet/IP ».
Dans Studio 5000
Son profil crée les tags : PF525:O.Start, PF525:O.Stop, PF525:O.FreqCommand, PF525:I.Active, PF525:I.Faulted, PF525:I.OutputFreq (les noms peuvent varier un peu selon la version du profil).
La consigne est en centièmes de hertz
Hz → j'écris3000dans FreqCommand
Le piège
Écrire 60 dans FreqCommand donne 0,60 Hz. Et si P046 / P047 ne sont pas sur EtherNet/IP, le variateur ignore le réseau… sans triangle jaune !

POINT I/O 1734-AENT

adaptateur
Son rôle
La « tête » d'un rail d'E/S déportées : il envoie l'état des entrées (IB8) et reçoit l'ordre des sorties (OB8E), au RPI. On câble les capteurs près de la machine, un seul câble Ethernet revient à l'automate.
Son adresse : les trois roulettes

Méthode du labo : roulettes sur 888 et redémarrage (retour usine) → BOOTP-DHCP Server : adresse MAC → 10.20.49.63 → Disable BOOTP/DHCP → roulettes sur 999 et redémarrage.

Dans Studio 5000
Sous Ethernet, puis ses modules dessous, dans l'ordre du rail. Chassis Size = nombre de modules + l'adaptateur (ici 4). Tags en général : POINT_IO:1:I.Data.0 (entrée 0), POINT_IO:2:O.Data.0 (sortie 0) ; le nom exact dépend de la connexion choisie.
Le piège
Chassis Size faux ou modules dans le mauvais ordre : triangles jaunes. Roulettes laissées sur 888 : retour usine à chaque démarrage.

Le switch (commutateur)

Son rôle
Le carrefour : il apprend quelle adresse MAC est sur quel port et envoie chaque trame seulement au bon port (un vieux hub, lui, copiait tout partout).
Non géré ou géré ?
Non géré (ex. Stratix 2000 du poste, 1783-US05T) : rien à régler, pas d'adresse. Géré (ex. Stratix 5700) : IGMP snooping pour le multicast, réseaux virtuels (VLAN), diagnostic port par port.
Les formes de réseau
Étoile : tout passe par le switch (notre exemple). Linéaire : on chaîne les appareils à deux ports (L30ER, 1734-AENTR). Anneau DLR : la chaîne est refermée, un câble coupé ne coupe rien.
Le piège
Ne branchez pas le réseau de la machine sur le réseau du bureau sans routeur ni pare-feu.

Le PC… et d'autres

Le PC portable
Studio 5000 (programmer, aller en ligne), FactoryTalk Linx ou RSLinx Classic (RSWho : voir tous les appareils du réseau), BOOTP-DHCP Server (donner une adresse). Adresse fixe dans Windows : 10.20.49.x, masque 255.255.255.0.
Le deuxième automate (PLC2)
Un autre L30ER : il produit des tags que PLC1 consomme, et PLC1 peut lui envoyer des MSG. C'est le montage des travaux sur les tags produits / consommés et sur la MSG.
Et encore
ControlLogix avec sa carte 1756-EN2T, caméras et lecteurs de codes, robots, îlots de distributeurs pneumatiques, et même des automates d'autres marques : un Siemens S7-1500 peut être scanner EtherNet/IP. Tous parlent CIP.
Le piège
Un PC dans un autre sous-réseau ne voit rien dans RSWho. Vérifiez d'abord son adresse.
Automate = scanner. AENT et variateur = adaptateurs. Écran et PC = clients qui demandent.

Teste-toi

À retenir

  • EtherNet/IP = Ethernet ordinaire + TCP/IP + CIP. IP = Industrial Protocol.
  • Implicite = E/S cycliques, au RPI, UDP 2222 : AENT, variateur, tags produits / consommés.
  • Explicite = question → réponse, TCP 44818 : MSG, PanelView, Studio 5000, RSWho.
  • RPI = le rythme des E/S réseau. Le plus lent qui suffit. Il ne suit pas le scan.
  • Implicite = rien à programmer : on ajoute l'appareil dans I/O Configuration, avec la même adresse IP que l'appareil.
  • Le PanelView n'est pas dans I/O Configuration : il passe par un raccourci FactoryTalk Linx.
  • PowerFlex 525 : P046 = 5, P047 = 15, consigne en centièmes de Hz.
  • 1734-AENT : roulettes 888 = retour usine, 999 = adresse en mémoire ; Chassis Size = modules + adaptateur.
  • Triangle jaune ? Le code dit tout : 16#0204 la cible ne répond pas, 16#0203 connexion perdue.
  • Dépanner dans l'ordre : câble → NS → ping → RSWho → code d'erreur.
