=Opérateurs et affectation

Affectation :=

Écrit une valeur dans un tag (garde sa valeur au prochain scan).

Moteur := 1;

Affectation non rétentive [:=]

Le tag est remis à 0 à l'entrée en mode Run ou au redémarrage.

Alarme [:=] Defaut;

Arithmétique + - * / MOD **

Addition, soustraction, multiplication, division, reste, puissance.

Total := Lot * 12 + Reste;

Comparaison = <> < <= > >=

Compare deux valeurs, donne VRAI ou FAUX.

Plein := Niveau >= 95.0;

Logique AND OR XOR NOT

Combine des conditions BOOL (AND s'écrit aussi &).

Marche := Start AND NOT Arret;

Commentaires // (* *) /* */

Explique le code ; ignoré par l'automate.

⇄Structures de contrôle

IF … THEN … ELSIF … ELSE … END_IF;

Exécute un bloc selon une ou plusieurs conditions.

IF Capteur THEN
  Verin := 1;
ELSE
  Verin := 0;
END_IF;

CASE … OF … END_CASE;

Choisit un bloc selon la valeur d'un entier — idéal pour une séquence par étapes.

CASE Etape OF
  0: IF Start THEN Etape := 10; END_IF;
  10: Moteur := 1;
ELSE
  Etape := 0;
END_CASE;

FOR … TO … BY … DO … END_FOR;

Répète un bloc un nombre connu de fois (parcourir un tableau).

FOR i := 0 TO 9 DO
  Tab[i] := 0;
END_FOR;

WHILE … DO … END_WHILE;

Répète tant que la condition est VRAIE (attention au chien de garde).

WHILE i < 10 DO
  i := i + 1;
END_WHILE;

REPEAT … UNTIL … END_REPEAT;

Répète au moins une fois, jusqu'à ce que la condition soit VRAIE.

REPEAT
  i := i + 1;
UNTIL i >= 10
END_REPEAT;

EXIT;

Sort immédiatement d'une boucle FOR, WHILE ou REPEAT.

IF Tab[i] = 0 THEN EXIT; END_IF;

⏱Temporisations et compteurs

TONR

Temporisation au travail (tag de type FBD_TIMER) : .TimerEnable, .PRE, .Reset → .DN, .ACC.

T1.TimerEnable := Capteur;
T1.PRE := 3000;
TONR(T1);
Lampe := T1.DN;

TOFR

Temporisation au repos : .DN reste VRAI pendant .PRE ms après la chute de l'entrée.

T2.TimerEnable := Marche;
T2.PRE := 5000;
TOFR(T2);
Ventilo := T2.DN;

RTOR

Temporisation cumulative : garde .ACC quand l'entrée tombe ; remise à zéro par .Reset.

T3.TimerEnable := Moteur;
T3.PRE := 60000;
T3.Reset := RAZ;
RTOR(T3);

CTUD

Compteur/décompteur (tag FBD_COUNTER) : .CUEnable, .CDEnable, .PRE, .Reset → .DN, .ACC.

C1.CUEnable := Photocellule;
C1.PRE := 10;
C1.Reset := RAZ;
CTUD(C1);
BoitePleine := C1.DN;

OSRI / OSFI

Front montant / descendant (tag FBD_ONESHOT) : .InputBit → .OutputBit pendant un scan.

OS1.InputBit := Bouton;
OSRI(OS1);
IF OS1.OutputBit THEN
  Cpt := Cpt + 1;
END_IF;

√Mathématiques

ABS

Valeur absolue.

Ecart := ABS(Consigne - Mesure);

SQRT

Racine carrée.

Debit := K * SQRT(Pression);

TRN

Tronque : enlève la partie décimale.

Entier := TRN(Valeur);

LN / LOG

Logarithme naturel / logarithme base 10.

dB := 20.0 * LOG(Rapport);

SIN / COS / TAN

Fonctions trigonométriques (angle en radians).

Y := R * SIN(Angle);

DEG / RAD

Convertit radians → degrés / degrés → radians.

Angle := RAD(45.0);

⇉Déplacement et tableaux

COP

Copie un bloc de données (tableau, structure) octet par octet.

COP(Source[0], Dest[0], 10);

CPS

Copie synchrone : les données ne changent pas pendant la copie (E/S, HMI).

CPS(Local:1:I.Data, Image, 1);

SIZE

Donne le nombre d'éléments d'un tableau.

SIZE(Tab, 0, Nb);

TOD / FRD

Entier → BCD / BCD → entier (afficheurs 7 segments, roues codeuses).

Afficheur := TOD(Compte);

AaChaînes de caractères

CONCAT

Colle deux chaînes bout à bout.

CONCAT(Texte1, Texte2, Message);

MID

Extrait une partie d'une chaîne.

MID(Code, 3, 1, Lot);

FIND

Cherche une chaîne dans une autre, donne la position.

FIND(Message, Cle, 1, Pos);

INSERT / DELETE

Insère / enlève des caractères dans une chaîne.

DELETE(Message, 2, 1, Court);

DTOS / STOD

Nombre entier ↔ chaîne.

DTOS(Compte, TexteCompte);

RTOS / STOR

Nombre réel ↔ chaîne.

RTOS(Temperature, TexteTemp);

UPPER / LOWER

Met une chaîne en majuscules / minuscules.

UPPER(Saisie, SaisieMaj);

⚙Programme et système

JSR / SBR / RET

Appelle une sous-routine, reçoit ses paramètres, retourne au programme.

JSR(Sequence_Remplissage, 0);

GSV / SSV

Lit / écrit une donnée système (heure, défauts, état du module).

GSV(WallClockTime, , LocalDateTime, Heure[0]);

MSG

Envoie un message à un autre automate ou module (tag MESSAGE).

IF NOT Msg1.EN THEN
  MSG(Msg1);
END_IF;

PIDE

Régulateur PID amélioré (tag PIDE) : .PV, .SP → .CVEU.

Reg.PV := Niveau;
Reg.SP := 50.0;
PIDE(Reg);
Vanne := Reg.CVEU;

SCL

Mise à l'échelle linéaire d'une valeur (tag SCALE).

S1.In := Brut;
SCL(S1);
Pression := S1.Out;

!À retenir

  • Chaque instruction se termine par un point-virgule ;.
  • En ST, on n'utilise pas MOV : on écrit simplement Dest := Source;.
  • Les temporisations et compteurs du ST (TONR, TOFR, RTOR, CTUD) utilisent des tags FBD_TIMER / FBD_COUNTER — pas TIMER / COUNTER.
  • Une boucle WHILE ou REPEAT trop longue déclenche le chien de garde de la tâche : préférer FOR quand on connaît le nombre de tours.
  • Le ST n'est pas sensible aux majuscules : moteur et Moteur sont le même tag.
