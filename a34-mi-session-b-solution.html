1. La station et le barème

Une case du convoyeur = un bit du registre Suivi[0]. La buse de soufflage est devant le bit 4.

La caméra dit s’il y a une pomme (S_Pomme) et si une tache est vue (S_Tache). Chaque appui sur BP_Avance fait avancer les pommes d’une case ; BP_Recul les fait reculer d’une case. Une pomme tachée est suivie dans le registre jusqu’au bit 4, où la buse la souffle dans le bac de rejets. Les bonnes pommes sont comptées dans la goulotte d’emballage (pleine à 5).

2. B1 · Configuration du poste · 10 points

B1.1 · Le projet et le contrôleur (3 pts)

  1. File → New : choisissez le contrôleur de votre poste et nommez le projet A34_MiSession_B_VotreNom (pas d’espace : des traits de soulignement).
  2. Le bon modèle et la bonne révision. La révision du projet doit être celle du firmware de l’automate (elle s’affiche dans Who Active quand on clique sur l’automate), sinon le téléchargement est refusé.
  3. L’adresse IP de l’étiquette : Controller Properties → Internet Protocol, puis le chemin de téléchargement par Communications → Who Active.

B1.2 · Les modules d’entrées et de sorties (3 pts)

Poste 1 (GuardLogix). Les boutons et les voyants sont sur les cartes 1756 du châssis. Le GuardLogix les atteint par le module Ethernet du slot 8, qu’on nomme CLX.

  1. I/O Configuration → Ethernet → New Module : le module Ethernet 1756 du slot 8 (son modèle est écrit sur la carte). Nom CLX, adresse 172.23.83.10, châssis de 10 slots, slot 8. Connexion : None.
  2. Sous le fond de panier de CLX : New Module → la carte d’entrées 16 points dans le slot 0, puis la carte de sorties 16 points dans le slot 1 (modèles écrits sur les cartes).
  3. Studio 5000 crée les tags des cartes : CLX:0:I.Data (entrées) et CLX:1:O.Data (sorties). Un bouton = un bit : CLX:0:I.Data.2, par exemple.
Pourquoi « None » ? Chaque carte a alors sa propre connexion et ses propres tags CLX:0:I et CLX:1:O, comme le demande l’énoncé. Avec « Rack Optimization », les données passeraient par CLX:I.Data[0] à la place.

Postes CompactLogix. Les cartes sont à côté de l’automate : leurs tags s’appellent Local:1:I.Data, Local:2:O.Data… (le numéro = la position de la carte sur votre poste).

B1.3 · Les tags alias, et les adresses notées sur l’énoncé (2 pts)

New Tag → Type Alias → Alias For : l’adresse du bouton ou du voyant → portée contrôleur. Écrivez la même adresse dans la première colonne de l’énoncé.

Ces adresses sont un exemple. La bonne adresse est celle du bouton ou du voyant câblé sur votre poste : suivez le fil, ou appuyez sur le bouton et regardez quel bit change dans Monitor Tags.

B1.4 · Le raccourci PLC_Exam dans FactoryTalk View ME (2 pts)

  1. Dans FactoryTalk View Studio, application A34_MiSession_B_VotreNom : RSLinx Enterprise → Communication Setup.
  2. Add → nommez le raccourci PLC_Exam.
  3. Onglet Design (Local) : déroulez le réseau Ethernet et cliquez sur votre automate (poste 1 : le 5069-L306ERMS2 à 172.23.83.14) → Apply.
  4. Copy from Design to Runtime → OK. Les tags s’écrivent ensuite {::[PLC_Exam]NomDuTag}.

3. Le programme, ligne par ligne (B2 à B5)

Seize lignes dans la routine principale, numérotées 0 à 15 comme dans Studio 5000. D’autres solutions sont justes si le comportement est le même et si les instructions demandées sont utilisées.

fil sous tensioncontact ou bobine en vert = instruction vraie( L ) OTL · ( U ) OTU
Le pupitre fait tourner ce programme. Il est à droite (ou en bas sur un petit écran) : appuyez sur ses boutons et les lignes s’allument comme dans Studio 5000 en ligne.
Astuce Studio 5000 : double-cliquez sur le numéro d’une ligne pour taper son texte. Le bouton « Copier le texte » de chaque ligne vous le donne prêt à coller.
